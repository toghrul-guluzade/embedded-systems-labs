# Embedded Systems Labs

This repository contains a collection of embedded systems experiments and laboratory projects developed for the ATmega328P microcontroller. The projects explore low-level programming concepts including GPIO control, timing, serial communication, sensor interaction, and simple host–device interfaces.

The code is written primarily in C and compiled using `avr-gcc`, with firmware uploaded using `avrdude`. The repository is organized so that each lab is a self-contained firmware project while reusable components and external libraries are stored separately.

---

## Overview

The goal of this repository is to provide a structured workspace for experimenting with microcontroller programming and embedded system concepts. Each project focuses on a specific topic, gradually building from basic hardware control to more complex interactive systems.

Examples of explored topics include:

* GPIO timing and digital signal behavior
* Analog input processing
* Joystick control and PWM LED output
* Real-time clock interaction
* Serial communication between microcontroller and host computer
* Simple graphical dashboards using Python and HTML

The projects are intended to run on an **ATmega328P-based board** such as an Arduino Uno.

### `projects/`

Contains individual firmware projects.
Each project typically includes:

```
project_name/
├── include/    # project headers
└── src/        # firmware source files
```

Some projects also include a `gui/` folder containing a small host-side interface (Python + HTML) used for monitoring data from the microcontroller.

---

### `lib/`

Shared libraries used across projects.

`external/`
Third-party libraries imported from external sources.

`myLib/`
Personal experimental modules and reusable utilities developed during earlier experiments.

---

### `build/`

Compilation output generated by the Makefile.

Typical output:

```
build/<project>/
    project.elf
    project.hex
```

These files are produced automatically when building a project.

### `flash.sh`

A small helper script that uploads compiled firmware to the microcontroller using `avrdude`.

## Requirements

The following tools must be installed:

* avr-gcc
* avr-libc
* avrdude
* make

On Ubuntu or Debian systems they can be installed with:

```
sudo apt install gcc-avr avr-libc avrdude make
```

---

## Building a Project

From the repository root, build a specific project by specifying its name:

```
make PROJECT=lab01_gpio_timing
```

Example:

```
make PROJECT=lab03_rtc_reaction_timer_game
```

This produces:

```
build/lab03_rtc_reaction_timer_game/lab03_rtc_reaction_timer_game.hex
```

---

## Flashing Firmware

After compiling a project, upload the firmware to the microcontroller:

```
./flash.sh lab03_rtc_reaction_timer_game
```

The script will locate the generated `.hex` file and upload it using `avrdude`.

Default configuration in `flash.sh`:

* Port: `/dev/ttyACM0`
* MCU: ATmega328P
* Baud rate: 115200
* Programmer: Arduino bootloader

Modify the script if your device uses a different serial port.

---

## Example Workflow

```
make PROJECT=lab02_joystick_led_control
./flash.sh lab02_joystick_led_control
```

1. The Makefile compiles the firmware.
2. A `.hex` file is produced in the `build/` directory.
3. `flash.sh` uploads the firmware to the microcontroller.
